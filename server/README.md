# Neon Territory Multiplayer Server

## Setup (Windows)

1. Repository pullen
2. In den Ordner wechseln:
   cd server

3. Server starten:
   start_server.bat

ODER manuell:

   npm install
   npm start

## Ergebnis

Server läuft auf:
http://localhost:3000

## Test

- Öffne dein Spiel in zwei Browser Tabs
- Beide verbinden sich mit dem Server
- Beide sehen sich live
